## 동일 입력 비교

사용자가 공개 강연 사용을 승인했다. CC BY-SA 4.0 한국어 기술 강연 세 편에서 각각 원본 02:00–12:00을 한 번씩 16 kHz mono Float32로 변환했다. 강연마다 9,600,000프레임을 겹치지 않는 20초 구간 30개로 나눴다. 네 후보에 입력한 360개 요청의 해시, 프레임 범위와 순서를 대조했다. 각 후보·강연 쌍은 모델을 한 번 로드한 한 세션에서 끝까지 진행했다.

측정 환경은 Mac16,8 arm64, 12 CPU, 24 GiB, macOS 26.6.2였다. 네트워크를 차단하고 후보 순서를 강연별로 순환했다. 한국어 transcribe, temperature 0, 힌트 없음, partial과 타임스탬프 사용 조건으로 1회 측정했다. 별도 추론 워밍업과 재시도는 0회다.

| 후보 | 완주 강연 | 정상 final / 90 | 빈 final | 강연 1 / 2 / 3 RTF | 최대 footprint (GiB) |

| WhisperKit + large-v3 | 1/3 | 88 | 13 | — / 0.227 / — | 0.422 |
| WhisperKit + large-v3-turbo | 2/3 | 89 | 8 | — / 0.065 / 0.055 | 0.216 |
| **whisper.cpp + large-v3** | **3/3** | **90** | **0** | **0.072 / 0.078 / 0.066** | **3.516** |
| whisper.cpp + large-v3-turbo | 2/3 | 89 | 0 | 0.034 / — / 0.032 | 1.870 |

12회의 실행 중 8회가 모든 구간에서 final을 반환했다. 나머지 4회에는 각각 한 번의 `invalidResponse`가 있었고 마지막 구간까지 모두 시도했다. 빈 final은 정상 종료 건수에 포함한다. RTF는 완주한 강연의 총 추론 시간 ÷ 600초이며 로드와 prewarm은 제외한다. 표의 대시는 미완주 강연이다.

## 명세 17.5 평가

| 항목 | 관측 및 한계 |
| --- | --- |
| 한국어 본문 정확도 · 40% | 사전에 지정한 초·중·후반 9개 구간과 90개 전체 구간의 원음·전사를 제공했다. 배포처에 시간 자막이 없고 사용자 채점도 없어 CER와 한국어 점수는 미산정이다. |
| 영어·전공 용어 보존 · 25% | 같은 발화를 네 열에 배치했다. 발표 자료의 참고어와 영문 표기가 갈린 추가 사례를 청취할 수 있다. 발화별 정답과 출현 분모가 확정되지 않아 보존율은 미산정이다. |
| 환각·반복·누락 · 20% | 빈 final과 실패 위치를 원음에 연결했다. 빈 final이 실제 무음인지 발화 누락인지는 청취 판정이 필요하다. 사건 수와 점수는 미산정이다. |
| 지연·대기열 · 10% | 선택 조합은 90/90개에서 partial을 관측했다. 제출부터 첫 partial까지 p50/p95는 1.471/1.715초, final까지는 1.471/1.715초다. 세 RTF 모두 목표 0.83 이내였고 20초 단위 유입 모의 최대 대기는 0초였다. 로컬 채점 기준으로 5/5점이다. |
| 메모리·안정성 · 5% | 선택 조합은 3/3 완주, 실패·재시도·경고 0회였다. 프로세스 기준선은 약 0.039 GiB, 관측 최고치는 3.516 GiB였다. 로컬 채점 기준으로 5/5점이다. |

WhisperKit은 토큰 진행 콜백, whisper.cpp는 완성된 세그먼트 콜백에서 partial을 낸다. 배치 제출 지연은 마이크 발화 기준 지연과 측정 시작점이 다르다. 50 ms 간격의 프로세스 footprint에는 짧은 피크와 GPU·ANE 메모리 일부가 빠질 수 있다. 실제 사용자의 강의실 녹음, 장시간 라이브 큐, 2시간 안정성은 이 표본의 검증 범위 밖이다. 품질 3개 항목에 청취 점수가 없어 100점 총점과 정확도 순위는 산출하지 않았다.

로컬 실행 `benchmark-results/t16/lecture.qWMHE5/REVIEW.html`에 원음, 출처·라이선스, 구간별 전사와 원시 측정 링크가 있다. 같은 PCM, 전 구간 시각, 12개 실행 및 검토 링크를 확인했고 브라우저에서 대표 구간 9개의 재생 위치를 검증했다. [재현 절차와 채점 기준](DEVELOPMENT.md#t16-developer-lecture-comparison)
